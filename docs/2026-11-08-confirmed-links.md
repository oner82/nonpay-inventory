# 확인된 재고 연결 반영 — 2026-11-08

사용자가 대화에서 확인한 내용으로 운영 재고 연결을 진행하도록 요청했다. 미확정 항목은 질문하고 답변 전 확정하지 않는다.

## 범위
- 기존 15개 직접 연결 유지·근거 기록. 새 직접 연결 9개: 이노그램, INTERGUARD, HEMOSTOP, MEDICLORE, WOUNDCLOT 5×5, HYVIXEL 3ml, Pulsavac-tip, SILASTIC DRAIN, PASSIVE SPHERE.
- Pulsavac-plus와 CARE BANDAGE는 사용량만 기록한다. Pulsavac은 tip에서만 1세트 차감.
- IRRIGATOR SET은 확인된 Linvatec/Stryker 제품 중 매 케이스 사용 제품을 선택한다. 선택은 코드의 고정 연결로 학습하지 않는다.
- 인체조직·앵커 12코드는 제품 대응을 확인 정보로 보관하되 별도 장부 연동은 답변 대기. 현재 OCS 자동 차감 대상에 추가하지 않는다.
- 보류 10코드: VELYS 묶음, 일반 드레이프 2종, EZ-CLOT, EASYENDO, shoulder pouch, 레노픽스, FAST-FIX, ICONIX SPEED, HydroCool. 불명확한 수량·규격·제품을 임의 연결하지 않는다.
- 제품·수량·과거 케이스·입고를 변경하지 않는다. 연결은 다음 처방 읽기부터 적용한다.

## 구현
- index_catalog_links.js: 관리자 전용 연결 파일 검증, 코드·명칭·제품 식별정보·기존 연결 대조, 전체 원자적 적용, 변경 전후 근거·작성자 기록, 재실행 무변경.
- index_storage_admin.js: 연결 미리보기 및 저장, 자동 핵심 자료 백업, 재조회 검증, 제품명·물류코드·연결 이유 표시.
- index_ocs.js: 선택 코드의 실제 사용 제품만 반영, 같은 코드 복수 행의 제품별 집계, 선택 결과로 기본 연결 덮어쓰기 방지. 보류·장부대기·차감 제외·확인된 고정 연결을 케이스 화면에서 우회 변경하지 못하게 보호.
- 보안 규칙·권한은 기존 승인된 관리자 범위를 그대로 사용한다.
